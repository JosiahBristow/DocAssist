这是什么

小程序 4 个页面的 Web 复刻版，用于在没有微信开发者工具时检查布局、走通流程、录演示视频。数据全部走本机 local-preview/server.js：格式校对用同一份规则引擎，速读/翻译调同一套云函数逻辑。

现在能验证什么

✅ 格式校对：真实校验，18 条规则

✅ PDF 解析 + 参考文献段抽取

✅ 论文原文预览：划词翻译 / 高亮备注 / 导出 Markdown

✅ 相似论文：国内平台检索链接 + OpenAlex/Crossref 结果

✅ 悬浮 AI 助手：划词提问 / 当前页截图 / 多轮对话

✅ 摘要/翻译链路（需 .env 里的 DeepSeek Key）
