# 文献助手 Android 客户端 · 安装说明

## 一、安装包

| 项 | 内容 |
|---|---|
| 文件名 | `文献助手-1.6.2.apk` |
| 路径 | `app-android/release/文献助手-1.6.2.apk` |
| 体积 | 约 4.3 MB |
| 包名 | `io.github.josiahbristow.docassist` |
| 版本 | 1.6.2（versionCode 10） |
| 签名 | 调试证书（v1 + v2 方案），仅用于安装测试 |

## 二、兼容系统

- **最低系统**：Android 5.1（API 22）
- **目标系统**：Android 14（API 34）
- **架构**：不限（纯 Java + WebView，无 native 依赖）
- **权限**：仅 `INTERNET`（访问大模型接口）与系统文件选择器（选 PDF，无需存储权限）

## 三、安装步骤

1. 把 `文献助手-1.6.2.apk` 传到手机（微信「文件传输助手」、数据线、网盘均可）。
2. 在手机的文件管理器里点击该 APK。
3. 首次安装会提示「未知来源应用」——进入设置允许该来源安装（不同厂商路径略有差异：
   小米=「安装未知应用」、华为=「外部来源应用下载」、OPPO/vivo=「未知来源安装」）。
4. 安装完成后桌面出现图标（蓝色圆角、「文」字），点击启动。

> 如果手机开启了「纯净模式」（华为/小米部分机型），需要临时关闭后再安装。

## 四、首次使用

1. **格式校对可以直接用**：首页 →「参考文献格式校对」→ 点「中文示例」或「英文示例」，无需账号与密钥。
2. **速读 / 翻译 / AI 助手需要你自己的 API Key**：
   - 首页 →「API 设置」→ 粘贴以 `sk-` 开头的 DeepSeek Key → 点「测试连接」→「保存到本机」。
   - Key 只保存在本机，不会上传到任何服务器；清除后立即失效。
   - 获取方式：手机浏览器打开 `platform.deepseek.com` → 注册登录 →「API keys」→ 创建 → 复制（只显示一次）。
   - 也可以改用其他 OpenAI 兼容服务，在「API 设置 → 高级」修改 Base URL 与模型名称。
3. **论文速读**：首页 →「论文速读」→ 选择 PDF（25MB 以内）→ 等待 10–30 秒。
   - 支持有文字层的 PDF（知网、arXiv、IEEE 下载的都可以）；扫描版会明确提示暂不支持。
   - 读完后点「检查这篇论文的参考文献」，会把该论文的参考文献自动转成国标格式。
4. **原文阅读与标注**：
   - 打开论文后默认在「原文」Tab，可缩放、双指捏合、划词翻译。
   - 选中文字后点浮条「高亮」可添加高亮和备注；点已有高亮可修改备注或「删除高亮」。
   - 浮动侧栏「笔」进入批注模式：单指书写、双指平移页面；可调粗细、颜色、撤销与橡皮。
5. **导出标注**：阅读页「导出」→
   - 「导出标注版 PDF」：把高亮和墨迹写入原 PDF，通过系统分享面板保存或发送。
   - 「导出 Markdown 笔记」：复制当前全部标注。

## 五、已知限制

- 扫描版 PDF 不支持（无 OCR）。
- 单文件 25MB 以内；超长论文按 6 段要点汇总，可能损失细节。
- AI 功能需自备 API Key；格式校对与标注不受影响。
- AI 助手的图片提问需要支持视觉的模型；DeepSeek 文本模型会拒绝图片请求。
- 若模型接口被校园网限制，可更换 Base URL 为其他 OpenAI 兼容服务。

## 六、卸载

桌面长按图标 → 卸载。卸载会一并清除本机保存的 API Key、论文库、标注与使用统计。
