# 文献助手 Android 客户端 · 安装说明

> 对应通知六（二）："APP 应提供安装包、兼容系统及安装说明"。

## 一、安装包

| 项 | 内容 |
|---|---|
| 文件名 | `文献助手-1.0.0.apk` |
| 路径 | 提交包内 `app-android/release/文献助手-1.0.0.apk` |
| 体积 | 4.4 MB |
| 包名 | `io.github.josiahbristow.docassist` |
| 版本 | 1.0.0（versionCode 1） |
| 签名 | 调试证书（v1 + v2 方案），仅用于本次评审安装测试 |

## 二、兼容系统

- **最低系统**：Android 5.1（API 22）
- **目标系统**：Android 14（API 34）
- **架构**：不限（纯 Java + WebView，无 native 依赖）
- **权限**：仅需 `INTERNET`（访问大模型接口）与系统文件选择器（选 PDF，无需存储权限）

## 三、安装步骤

1. 把 `文献助手-1.0.0.apk` 传到手机（微信「文件传输助手」、数据线、网盘均可）。
2. 在手机的文件管理器里点击该 APK。
3. 首次安装会提示"未知来源应用"——进入设置允许该来源安装（不同厂商路径略有差异：
   小米=「安装未知应用」、华为=「外部来源应用下载」、OPPO/vivo=「未知来源安装」）。
4. 安装完成后桌面出现图标（蓝色圆角、"文"字），点击启动。

> 如果手机开启了「纯净模式」（华为/小米部分机型），需要临时关闭后再安装。

## 四、首次使用

1. **格式校对可以直接用**：首页 →「参考文献格式校对」→ 点「中文示例」或「英文示例」，无需任何账号与密钥。
2. **速读 / 翻译需要你自己的 API Key**：
   - 首页 →「API 设置」→ 粘贴以 `sk-` 开头的 DeepSeek Key → 点「测试连接」（会显示"连接成功"）→「保存到本机」。
   - Key 只保存在本机，不会上传到任何服务器；清除后立即失效。
   - 获取方式：手机浏览器打开 `platform.deepseek.com` → 注册登录 → 「API keys」→ 创建 → 复制（只显示一次）。
3. **论文速读**：首页 →「论文速读」→ 选择 PDF（手机文件里选，25 MB 以内）→ 等待 10–30 秒。
   - 支持有文字层的 PDF（知网、arXiv、IEEE 下载的都可以）；扫描版会明确提示暂不支持。
   - 读完后点「检查这篇论文的参考文献」，会把该论文的参考文献自动转成国标格式。

## 五、与小程序端的关系

两端功能与结果一致，共用同一份规则引擎与提示词：

| | Android 客户端 | 微信小程序 |
|---|---|---|
| 格式校对 | 本机计算，离线可用 | 本机计算，离线可用 |
| 论文速读 | 本机解析 PDF + 直连模型 | 云函数解析 PDF + 调用模型 |
| 是否需要服务器 | 不需要 | 云开发（云函数 + 云存储） |
| 数据是否出设备 | 不出（仅模型请求） | 论文存云存储 |
| 安装方式 | 装 APK | 扫码用体验版 |

## 六、已知限制

- 扫描版 PDF 不支持（无 OCR）。
- 单文件 25 MB 以内；超长论文按 6 段要点汇总，可能损失细节。
- 预览版（调试签名）在部分机型上首次启动需 1–2 秒白屏，属正常。
- 若模型接口被校园网限制，可到「API 设置 → 高级」把 Base URL 改为其他 OpenAI 兼容服务（如硅基流动）。

## 七、卸载

桌面长按图标 → 卸载。卸载会一并清除本机保存的 API Key 与使用统计。
