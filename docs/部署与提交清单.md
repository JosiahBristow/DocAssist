## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 点速读一直转圈后失败 | 云函数超时 3 秒 | 改成 60 秒后重新部署 |
| 提示「需要配置你自己的 API Key」 | 用户还没填 Key | 进「API 设置」粘贴并保存；格式校对不需要 Key |
| 提示「API Key 无效或已失效」 | Key 复制不全 / 已删除 | 重新到 platform.deepseek.com 生成一个 |
| 提示「账户余额不足」 | DeepSeek 账户没钱 | 充值，或换用硅基流动等兼容接口（高级设置可改 Base URL） |
| 报 `缺少依赖 pdf-parse` | 部署时选了「上传所有文件」而非「云端安装依赖」 | 重新右键上传并部署，选云端安装依赖 |
| 提示「扫描版 PDF」 | PDF 是图片扫描件 | 换一篇有文字层的（知网下载的 PDF 一般没问题） |
| 选文件里找不到 PDF | 小程序只能从聊天记录选文件 | 先发到「文件传输助手」，再在该会话里选 |
